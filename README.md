# ScoutForge – güncellemeler

Bu depo yalnızca ScoutForge'un kurulum ve güncelleme dosyalarını barındırır
(**Releases** bölümü). Kaynak kodu burada değildir.

Uygulama yeni sürümleri buradan kendiliğinden bulur ve kurar.
İlk kurulum için en son sürümün `ScoutForge_..._x64-setup.exe` dosyasını
[Releases](https://github.com/Labu1/scoutforge/releases/latest) sayfasından indirin.
